# MCRangers — マインクラフト戦隊 登場演出メーカー

Minecraftの3Dキャラクターで「5人戦隊」の登場演出を作れるエンタメWebアプリ。
メンバーごとの紹介シーンが順番に流れ、最後に大爆発を背負ったチーム紹介で締めます。

HTML + JavaScript のみで動作し、ビルドもサーバーも不要です(Three.jsはCDNから読み込み)。

## 起動方法

ES Modulesを使っているため、ローカルではHTTPサーバー経由で開いてください。

```sh
cd mcrangers
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

(`npx serve` など任意の静的サーバーでもOK)

## 使い方

1. 戦隊名・二つ名(任意)・チーム紹介演出を入力
   - 戦隊名が未入力の場合は「{1人目の名前}と愉快な仲間たち」になります
2. メンバー(最大16人)を追加
   - メンバー名 / 二つ名(任意) / 決め台詞(任意) / Minecraft Java版のUsername(またはUUID) / 戦隊カラー / 個人紹介演出
   - 決め台詞は名乗りの瞬間にキャラの頭上へコミック風の吹き出しで表示される
   - 戦隊カラーはプリセット16色のほか、カラーピッカーまたは
     HEX(`#ff3b30`)・RGB(`255,59,48` / `rgb(255,59,48)`)の直接入力で自由に指定可能
     (おまかせなら並び順で自動割当)。タイトル演出の色・名乗りのリング色・
     スキン取得失敗時のスーツ色に使われます
3. 「スーツ統一」をONにすると、全員が体だけメンバーカラーの戦隊スーツになる
   (顔は本人のスキンのまま。Usernameなしのメンバーはヘルメット付きフルスーツ)
4. 「出撃！」で演出開始
   - 演出はURL(`?d=...`)として共有できます。エンドカードの「URLをコピー」から取得
   - クリック / Space で次のシーンへスキップ、Esc で編集に戻る

## 技術メモ

- **背景世界**: MC風のプロシージャルテクスチャ(草・土・石・砂・テラコッタ等)を
  貼ったInstancedMeshのボクセル地形(`js/world.js`)。環境ごとに草原+木+雪山、
  夕焼けメサ、洞窟、エンド風など全シーンが立方体ワールドで構成される
- **Mob**: クリーパー / ブタ / ニワトリ / ヒツジ / ハチ / オオカミ /
  アイアンゴーレム / エンダーマン / エンダードラゴン / ウォーデン / アレイ /
  ウーパールーパー / ラクダ / ガスト / ウィザー(簡易ボクセルモデル)+
  ゾンビ・スケルトン・村人(生成スキンを着た人型リグ)を演出に活用
- **3Dモデル**: バニラのMinecraftモデルではなく、肘・膝で曲がる8セグメントの独自リグ
  (`js/player.js`)。スキンUVを上腕/前腕・腿/脛に分割マッピングし、関節には隙間埋めキューブ入り
- **スキン取得** (`js/skin.js`):
  1. [PlayerDB](https://playerdb.co) でusername→UUID解決 → [mineatar](https://mineatar.io) で生スキン取得
     (UUIDは不変なのでキャッシュ汚染に強く、スキンが最新で取れる)
  2. フォールバック: [Ashcon API](https://github.com/LucasPickering/ashcon) — UUID+slim+スキン一括(キャッシュが古いことがある)
  3. 旧式64x32スキンは64x64へ自動変換、不透明オーバーレイ(旧式の色キー)は自動除去
  4. slim(Alex型)はテクスチャの透明領域からも自動判定
- **効果音**: WebAudioでリアルタイム合成(外部音源ファイルなし)
- **タイトル演出**: HTML/CSSオーバーレイ(Reggae One + DotGothic16)
- **開発用**: `tools/poses.html` でキメポーズ一覧を確認可能

## ファイル構成

```
index.html        エントリ
css/style.css     UI・タイトル演出
js/app.js         アプリ本体 (フォームUI / シーン進行 / メインループ)
js/core.js        定数・状態・URL共有・イージング等ユーティリティ
js/skin.js        スキン取得・変換 (PlayerDB / mineatar / Ashcon)
js/engine.js      描画・音基盤 (ステージ / ボクセル地形 / パーティクル / 効果音 / タイトル)
js/actors.js      登場物 (関節付きプレイヤー / ポーズ / 小道具 / Mob)
js/scenes.js      個人紹介演出 x64 + シーン共通フレームワーク
js/team.js        チーム紹介演出 x16
```
